Image API

One simple API to search and optimize images from Unsplash, Pexels, and Pixabay.

Get Started View Documentation

Introduction

The StockIt API aggregates millions of free-to-use images from the web's best sources with built-in optimization.

Base URL

~ % https://stockit.vercel.app
GET

/search

Search for images across all supported providers.

Query Parameters

Parameter Type Description
q string Search query Required
lim integer Results to return (default: 30, max: 500)
ext string Format: jpg, png, webp
quality integer Compression quality (1-100, default: 90)
orientation string Filter: p (portrait), l (landscape), s (square)

Example Request

zsh
~ % curl \
"https://stockit.vercel.app/search?
q=cyberpunk&lim=5&ext=webp&
quality=50"

Example Response

response.json 
{
  "count": 1,
  "query": "cyberpunk",
  "results": [
    {
      "id": "unsplash_abc",
      "source": "unsplash",
      "url": "..."
    }
  ]
}

Additional Endpoints

Specialized endpoints for different use cases.

GET

/all

Fetches random images from curated topics or search results.

~ % /all?ext=png
GET

/{source}

Query a specific provider directly for targeted results.

/unsplash /pexels /pixabay
GET

/url

Scrape and extract images from any public website URL.

~ % /url?q=site.com
GET

/convert

Real-time image optimizer and format converter.

Parameters

url The absolute URL of the image source
ext Target format (jpg, png, webp)
quality Compression level from 1-100

Auto-Configuration

You usually don't need to call this endpoint manually.

When you pass ext=webp to the search endpoint, all returned URLs automatically point here with optimized parameters.
